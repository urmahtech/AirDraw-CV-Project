# AirDraw CV Project

## Overview
AirDraw is a computer vision application that allows users to draw in the air using hand gestures. The project is built using Python, OpenCV, and MediaPipe.

## Features
- Draw using index finger
- Select colors using hand gestures
- Eraser tool
- Clear canvas
- Save drawings
- Real-time hand tracking

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Installation

```bash
pip install -r requirements.txt
python -m src.main
```

## Controls

- Index finger → Draw
- Index + Middle finger → Select color
- Fist → Pause
- Open Palm → Clear canvas
- Q → Quit
- S → Save drawing
